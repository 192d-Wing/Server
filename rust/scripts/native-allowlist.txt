# Any package in a shipping target's dependency graph whose manifest declares
# `links` must be listed here FOR THAT TARGET, or the check fails.
#
# Format (one entry per line; `#` starts a comment):
#   <crate> <class> <targets> # rationale (approved: <date>, <run>)
#
# <class>:
#   native         links native code into shipped binaries
#   native-unused  native code linked but never called; outside the FIPS boundary
#   build-native   native code used on the build host only, never shipped
#   marker         `links` used only as a version-uniqueness marker; no native code
# <targets>: comma-separated target triples, or `all`
#   (all = x86_64-unknown-linux-gnu, aarch64-unknown-linux-gnu, wasm32-unknown-unknown).
#
# No aws-lc-* entry may ever cover wasm32-unknown-unknown.
# Adding an entry needs an approved plan entry (CM-3) and a rationale.
